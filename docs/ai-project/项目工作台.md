## 项目定义

- 核心问题：Windows 自带剪贴板历史不够适合高频鼠标检索、显式复制、图片预览和本地隐私控制。
- 目标用户或调用方：在 Windows 上频繁复制文本、代码、链接和截图的个人用户。
- 项目目标：提供通过 `Alt + V` 快速呼出的轻量本地剪贴板工作台。
- 成功结果：用户可在持续置顶看板中快速检索、鼠标选择并复制文本或图片，再到目标应用手动粘贴，且后台资源占用受控。
- MVP：文本/图片历史、搜索、鼠标显式复制、上下键辅助选择、收藏、删除、托盘、暂停、排除程序、清理策略。
- 明确不做：云同步、账号、OCR、AI、富文本完整还原、文件历史、多平台和自动更新。
- 核心流程：复制内容 → 捕获并持久化 → 快捷键打开置顶看板 → 搜索或鼠标选择 → 显式复制 → 用户切换应用并手动 `Ctrl + V`。
