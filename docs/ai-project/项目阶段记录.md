## ATOM-22 验证摘要

- 状态：已完成，最终 DDD 结论为 PASS。
- 代码证据：`PasteFailureReason` 将桥接/写回失败与目标、焦点、输入失败分开；失败事件携带 generation、request_token 和类别，仅在面板可见、请求仍 pending 且代次/令牌匹配时消费；有效失败清理执行状态并重新显示面板，取消、成功、隐藏、新捕获和新请求清除提示。
- UI 证据：Slint 只接收固定提示文案，不展示正文、窗口标题或错误堆栈；失败提示同步独立于卡片模型刷新；`window.show()` 仅恢复面板可见性，不重新捕获目标、不重试 `Ctrl+V`。
- 桥接证据：包括 `CloseFailed` 在内的 `CopyProcessError` 统一保守归类为“无法准备剪贴板内容，请重试”，避免无法确认写回可用时误报“内容已复制”。
- 自动化验证：`cargo test --all-targets --locked` 通过 133 个测试；`cargo clippy --all-targets --all-features -- -D warnings`、Windows `cargo check`、Windows Release `cargo build`、中文注释检查和 `git diff --check` 均通过。
- 交付证据：代码提交 `f4647e6 feat(paste): 增加自动粘贴失败降级` 已推送 `origin/main`。
- 未完成边界：真实交互桌面管理员/输入失败场景仍需人工补测；搜索、图片、隐私清理和最终验收尚未开始或完成。
