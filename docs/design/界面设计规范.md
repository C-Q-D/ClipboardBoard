# ClipboardBoard 界面设计规范

## 文档范围

- 产品或模块：ClipboardBoard 浮动剪贴板看板及设置表面。
- 适用范围：Windows 桌面端 v1.0。
- 不适用范围：安装器、系统原生文件选择器和未来云功能。
- 批准方式或委托范围：用户已明确委托黑底白字方向；以下细节为试用规则，需在真实 Slint 渲染中验证。
- 最后验证时间：尚未开始代码渲染。

## 产品意图

- 产品目的：让用户以尽量少的视觉停顿找回并重用最近复制的内容。
- 主要用户：高频跨应用复制文本和截图的 Windows 用户。
- 使用环境：多窗口、短时高频、键盘优先。
- 核心任务优先级：打开与定位内容 > 选择与粘贴 > 搜索与筛选 > 管理与设置。
- 已确认业务约束：面板默认临时出现；内容涉及隐私；需要在高密度历史中保持可扫描性。

## 视觉命题与反目标

- 一句话视觉命题：像一块安静、锐利的黑色检索台，让用户在一瞥之间定位过去复制的片段。
- 与产品任务的关系：黑色底面减少环境噪声，清晰白字和细线层级优先服务搜索、选择和键盘焦点。
- 主导性表达：深黑连续工作面；高对比文字与单条细亮焦点线。
- 明确反目标：SaaS 仪表盘感、卡片瀑布、渐变、厚重阴影、过多彩色标签和过大留白。
- 最容易失效的场景：长中文文本、大量图片、窄窗口、高 DPI 和键盘选择焦点。

## 信息与布局语法

- 导航模型：单一浮动面板；顶部搜索与筛选；中央历史列表；底部快捷键提示。
- 页面骨架：16px 内边距，顶部工具区固定，列表区域独立滚动，底部提示固定。
- 内容宽度与栅格：默认 560px 宽；文本卡片固定高度约 72px，图片卡片固定高度约 176px。
- 密度策略：卡片采用细分隔与短摘要，不使用厚边框或多层容器。
- 信息层级：选中项 > 主摘要 > 图片预览 > 时间和来源 > 次级操作。
- 响应式规则：面板允许固定模式下缩放；最小宽度确保搜索、筛选和操作不重叠。

## 视觉令牌

| 类型 | 试用规则 |
|---|---|
| 背景 | `#080808` 主背景，`#111111` 选中或悬浮背景 |
| 主文字 | `#F5F5F5` |
| 次级文字 | `#8C8C8C` |
| 细分隔 | `#2A2A2A`，1px |
| 焦点 | `#FFFFFF` 细边或左侧 2px 线，不使用大面积蓝色 |
| 危险操作 | 限于清空/删除确认，使用低饱和红色文字或边框 |
| 字体 | 优先系统 UI 字体；文本摘要 14–15px，元信息 11–12px |
| 圆角 | 面板 14px；内部卡片 8px；避免胶囊泛滥 |
| 阴影 | 仅面板外层使用柔和深阴影；卡片不使用悬浮阴影 |
| 动效 | 100–150ms；只表达面板出现、选中变化和加载，不制造装饰性运动 |

## 状态与反馈

- 加载：列表保留已加载内容，并在底部显示轻量加载指示。
- 空数据：显示“复制内容后会显示在这里”，不展示装饰插画。
- 错误：用短句说明原因和下一步，不泄露隐私内容。
- 成功：复制或粘贴成功用短暂、低干扰反馈。
- 无权限：高完整性目标显示“已复制，请按 Ctrl + V”。
- 禁用：暂停记录时在顶部或托盘显示明确状态。
- 危险操作：清空全部必须使用文字强确认。
- 中断与恢复：缺失图片显示不可用状态，不显示可粘贴操作。

## 决策记录

### D-001 黑色命令面板语法

- 状态：试用。
- 决策：采用黑底、白字、细分隔、高密度固定高度历史卡片的命令面板语法。
- 原因：用户明确指定黑底白字；高频短时检索需要强层级和低环境干扰。
- 产品意图证据：用户的 Windows 剪贴板工具方案与黑底白字要求。
- 运行事实证据：当前为绿地项目，尚无遗留视觉系统。
- 视觉先例证据：无外部复制，直接由产品任务转译。
- 锁定决定：黑色基底、白色主文字、键盘焦点优先和固定高度列表。
- 适用与不适用范围：适用于主面板和设置；不强制覆盖 Windows 原生安装器。
- 批准者或委托依据：用户明确授权开始完整实现。
- 实现位置：Slint UI 文件与组件。
- 最后验证：待 ATOM-12、ATOM-37 的真实渲染。
- 重开或迁移条件：若高 DPI、可读性或图片列表性能无法满足验收，则调整布局令牌但保持产品意图。
