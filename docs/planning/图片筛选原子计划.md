## 总体计划

### 交付目标

用户可以点击“图片”标签，只查看 SQLite 中的图片历史；“全部”“文本”“图片”“收藏”
四个标签保持互斥，关键词搜索和复合游标续页继续作用于当前筛选集合。

### 现状证据

- `src/storage/worker.rs` 的 `HistoryQuery.item_type` 与参数化 SQL 已支持任意精确类型筛选，
  并在筛选条件内应用 `(copied_at, id)` 复合游标。
- `src/command.rs` 的 `SearchFilter` 目前只有全部、文本和收藏，未知索引回退全部。
- `src/app/ui_event.rs` 只把文本标签映射为 `item_type = "text"`。
- `ui/app-window.slint` 只显示全部、文本和收藏三个标签。

### 全局约束

- UI 和事件边界只传递受限枚举及稳定索引，不允许 UI 直接拼接数据库类型字符串。
- 图片筛选固定映射为 `item_type = "image"`；收藏筛选不限制类型。
- 切换标签继续复用现有防抖、数据集 generation、请求 token 和复合游标协议。
- 未知标签索引继续回退“全部”，不能产生任意类型查询。
- 不修改图片捕获、缩略图加载、复制写回、收藏、删除或清理语义。
- 新增和修改的代码、测试保持中文职责与关键规则注释。

### 验收场景

1. 点击“图片”后只显示图片记录，文本记录不出现。
2. “全部”显示文本和图片，“文本”只显示文本，“收藏”显示所有已收藏类型。
3. 图片筛选与关键词组合后仍只返回匹配图片。
4. 图片筛选跨页时按复合游标连续，不重复、不遗漏、不混入文本。
5. 未知 UI 标签索引安全回退“全部”。

### 明确排除

- 不重新实现通用分页协调器或滚动续页；这些属于 ATOM-40/41。
- 不实现缩略图 LRU；属于 ATOM-42。
- 不执行混合列表性能门禁；属于 ATOM-43。
- 不改变筛选标签的整体视觉语言。

## IMG-FILTER-01 启用图片类型筛选标签

- 状态：pending
- 支持的验收场景：上述 1 至 5。
- 唯一目标：把图片作为第四个受限筛选标签接入现有查询和分页链路。
- 当前行为与目标行为：当前用户只能选全部、文本或收藏；完成后可以选择图片，查询固定
  携带 `item_type = "image"`，并继续复用当前数据集和游标协议。
- 前置条件与依赖：ATOM-38 已完成并经用户验证；SQLite 已持久化图片摘要。
- 代码定位依据：
  - `src/command.rs`：`SearchFilter::{from_index, as_index}`。
  - `src/app/ui_event.rs`：`UiState::build_search_query` 与筛选 reducer 测试。
  - `src/storage/worker.rs`：`HistoryQuery` 参数化类型筛选与复合游标测试接缝。
  - `ui/app-window.slint`：筛选标签横向布局。
- 允许修改：上述枚举、查询映射、筛选标签、直接相关测试、本计划、根计划状态和项目工作台。
- 明确不修改：图片捕获/复制、通用分页协议、滚动触发、缩略图缓存、记录管理和设置。
- 实现步骤：
  1. 给 `SearchFilter` 增加 `Image`，分配稳定索引 2，并把收藏索引顺延为 3。
  2. 将图片筛选映射为固定 `item_type = "image"`；全部和收藏仍允许混合类型。
  3. 在现有标签组中加入“图片”，同步收藏标签索引与选中态。
  4. 扩展枚举边界、查询映射和真实 SQLite 图片筛选分页测试。
- 接口、数据与错误契约：标签索引 `0/1/2/3` 分别对应全部/文本/图片/收藏；其他值回退
  全部。查询仅使用参数绑定，不新增 SQL 字符串插值。
- 边界与异常：空结果沿用现有状态；关键词无匹配不回退全部；未知类型或无效图片摘要
  仍由既有转换层拒绝。
- 测试要求：
  - 枚举四个稳定索引与未知索引回退。
  - reducer 为图片生成 `item_type = "image"` 且不设置收藏条件。
  - 存储层以真实合法图片行验证图片筛选的关键词组合和跨页连续性。
  - Slint UI 编译并包含四个标签。
- 验证命令：
  - `cargo test --lib command::tests`
  - `cargo test --lib app::ui_event::tests::全部文本图片与收藏查询映射正确`
  - `cargo test --lib storage::worker::tests::history_query_image_filter_cursor_pages_are_stable`
  - `cargo check --bin clipboard-board`
- 预期结果：用户点击“图片”后只看到图片历史，继续滚动时结果集合保持稳定。
- 完成判定：上述针对性测试与检查通过，差异只包含本原子范围，程序可启动供人工验证。
- 交付给下一原子的输出：ATOM-40 可在四类筛选结果上复核统一分页状态和性能观测。
- 停止或重新规划条件：现有存储查询无法对合法图片行保持复合游标连续，且修复需要改变
  通用分页协议。
- 风险等级：L1
- DDD 门禁：不触发；受限枚举和已有参数化查询可由直接测试证明。
- 计划提交信息：`feat(filter): [IMG-FILTER-01] 支持图片类型筛选`
