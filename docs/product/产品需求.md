# ClipboardBoard 产品需求

## 文档范围

本文定义 Windows 轻量剪贴板工具 v1.0 的用户可见行为、边界和验收标准，不规定具体 Rust 模块或 Win32 调用方式。

## 用户与使用情境

- 主要用户：频繁复制文本、代码、链接和截图的 Windows 个人用户。
- 使用情境：浏览器、聊天工具、IDE、文档和截图工具之间快速切换。
- 核心诉求：快速找到过去复制的内容，优先键盘操作，并让敏感数据保持在本地。

## MVP 与优先级

| 编号 | 能力 | 优先级 | 行为 |
|---|---|---:|---|
| FR-01 | 快捷面板 | P0 | `Alt + V` 在当前显示器打开黑色面板，Esc、失焦或再次热键隐藏。 |
| FR-02 | 文本历史 | P0 | 复制 Unicode 文本后按最近时间显示，相同内容合并并置顶。 |
| FR-03 | 文本重用 | P0 | 上下键选择；Ctrl+Enter 仅复制；Enter 尝试粘贴。 |
| FR-04 | 本地持久化 | P0 | 重启后可恢复历史，收藏状态保留。 |
| FR-05 | 搜索与筛选 | P0 | 输入搜索文本或来源；可筛选全部、文本、图片和收藏。 |
| FR-06 | 记录管理 | P0 | 可收藏、删除、清空未收藏和强确认清空全部。 |
| FR-07 | 图片历史 | P1 | 捕获图片、显示缩略图、重新复制和粘贴。 |
| FR-08 | 浏览性能 | P1 | 无限滚动、游标分页、缩略图懒加载和有界缓存。 |
| FR-09 | 隐私 | P1 | 暂停记录、排除程序、默认不保存窗口标题。 |
| FR-10 | 设置与系统集成 | P1 | 托盘、开机启动、可改热键、固定窗口和清理限制。 |

## 核心流程

### 复制与记录

1. 用户在外部程序复制内容。
2. 应用判断当前是否暂停或来源是否被排除。
3. 应用捕获一个受支持的内容类型。
4. 应用按内容哈希合并或创建历史记录。
5. 记录提交成功后才在面板中可见。

### 选择与粘贴

1. 用户按 `Alt + V`。
2. 应用打开面板并聚焦搜索或当前选择。
3. 用户用箭头键、搜索或鼠标定位记录。
4. Ctrl+Enter 只写回系统剪贴板。
5. Enter 对普通权限目标尝试自动粘贴；高完整性或失败场景仅复制并提示用户手动粘贴。

## 用户可见状态

| 状态 | 必须表现 |
|---|---|
| 空历史 | 显示明确空状态和“复制内容后会显示在这里”。 |
| 搜索中 | 不清空已显示结果，显示轻量加载提示。 |
| 无搜索结果 | 显示关键词无结果状态。 |
| 记录暂停 | 托盘和面板显示暂停状态。 |
| 热键冲突 | 显示冲突说明和设置入口。 |
| 自动粘贴降级 | 显示“内容已复制，请按 Ctrl + V”。 |
| 图片缺失 | 不显示可粘贴假象，显示不可用状态并允许删除。 |
| 清空全部 | 使用强确认，明确会删除收藏。 |

## 数据与隐私规则

- 所有历史默认只存本机，不上传、不联网、不做遥测。
- 默认保存来源程序；默认不保存窗口标题。
- 暂停和排除必须在读取正文之前生效。
- 默认普通记录上限 2,000 条、保留30天、图片空间500 MiB。
- 收藏不参与自动清理，但用户明确删除或清空全部时可以删除。

## 非目标

- 账号、云同步、团队共享。
- OCR、AI 分类、网页联网解析。
- 完整 HTML/富文本粘贴还原。
- 文件、视频和音频历史。
- 跨平台支持和自动更新。
