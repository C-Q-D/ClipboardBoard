# ClipboardBoard 产品需求

## 文档范围

本文定义 Windows 轻量剪贴板工具 v1.0 的用户可见行为、边界和验收标准，不规定具体 Rust 模块或 Win32 调用方式。

## 用户与使用情境

- 主要用户：频繁复制文本、代码、链接和截图的 Windows 个人用户。
- 使用情境：浏览器、聊天工具、IDE、文档和截图工具之间快速切换。
- 核心诉求：快速找到过去复制的内容，以鼠标直接选择和复制为主、键盘快捷键为辅，并让敏感数据保持在本地。

## MVP 与优先级

| 编号 | 能力 | 优先级 | 行为 |
|---|---|---:|---|
| FR-01 | 快捷面板 | P0 | `Alt + V` 在当前显示器打开并置顶黑色面板；点击其他应用不隐藏；`Esc` 或再次按 `Alt + V` 隐藏到托盘。 |
| FR-02 | 文本历史 | P0 | 复制 Unicode 文本后按最近时间显示，相同内容合并并置顶。 |
| FR-03 | 文本重用 | P0 | 鼠标点击卡片选择，卡片提供明确“复制”按钮；上下键仅辅助选择；普通 Enter 和 Ctrl+Enter 均无动作，应用不模拟粘贴。 |
| FR-04 | 本地持久化 | P0 | 重启后可恢复历史，收藏状态保留。 |
| FR-05 | 搜索与筛选 | P0 | 输入搜索文本或来源；可筛选全部、文本、图片和收藏。 |
| FR-06 | 记录管理 | P0 | 可收藏、删除、清空未收藏和强确认清空全部。 |
| FR-07 | 图片历史 | P1 | 捕获图片、显示缩略图并重新复制，由用户在目标应用手动粘贴。 |
| FR-08 | 浏览性能 | P1 | 首批 30 条、后续每批 50 条的无限滚动、复合游标分页、缩略图懒加载和有界缓存。 |
| FR-09 | 隐私 | P1 | 暂停记录、排除程序、默认不保存窗口标题。 |
| FR-10 | 设置与系统集成 | P1 | 托盘、开机启动、可改热键、固定窗口和清理限制。 |

## 核心流程

### 复制与记录

1. 用户在外部程序复制内容。
2. 应用判断当前是否暂停或来源是否被排除。
3. 应用捕获一个受支持的内容类型。
4. 应用按内容哈希合并或创建历史记录。
5. 记录提交成功后才在面板中可见。

### 选择、复制与手动粘贴

1. 用户按 `Alt + V`。
2. 应用打开并持续置顶面板，聚焦搜索或当前选择。
3. 用户通过搜索、鼠标点击卡片或辅助方向键定位记录。
4. 用户点击卡片“复制”按钮，把精确内容写入系统剪贴板；不提供键盘复制快捷键。
5. 用户切换到目标应用并手动按 `Ctrl + V`；应用不恢复目标焦点、不模拟按键、不注入输入。
6. 用户按 `Esc` 时面板隐藏到系统托盘；点击其他应用不会隐藏面板。

## 用户可见状态

| 状态 | 必须表现 |
|---|---|
| 空历史 | 显示明确空状态和“复制内容后会显示在这里”。 |
| 搜索中 | 不清空已显示结果，显示轻量加载提示。 |
| 无搜索结果 | 显示关键词无结果状态。 |
| 记录暂停 | 托盘和面板显示暂停状态。 |
| 热键冲突 | 显示冲突说明和设置入口。 |
| 复制失败 | 显示固定、无正文的重试提示；面板保持显示。 |
| 图片缺失 | 不显示可粘贴假象，显示不可用状态并允许删除。 |
| 清空全部 | 使用强确认，明确会删除收藏。 |

## 数据与隐私规则

- 所有历史默认只存本机，不上传、不联网、不做遥测。
- 默认保存来源程序；默认不保存窗口标题。
- 暂停和排除必须在读取正文之前生效。
- 默认普通记录上限 2,000 条、保留30天、图片空间500 MiB。
- 收藏不参与自动清理，但用户明确删除或清空全部时可以删除。

## 非目标

- 账号、云同步、团队共享。
- OCR、AI 分类、网页联网解析。
- 完整 HTML/富文本粘贴还原。
- 文件、视频和音频历史。
- 跨平台支持和自动更新。
- 自动恢复目标窗口焦点、模拟 `Ctrl + V` 或其他输入注入。
